# Security

tinySA Screen talks to a tinySA over USB and to other programs through files in your home folder; it opens no network
connections.

If you find a security problem, please report it privately through
[a security advisory](https://github.com/tolgabalci/tinysa-screen/security/advisories/new) rather than an issue. You'll
get an answer within a week. Fixes go into the latest release.
