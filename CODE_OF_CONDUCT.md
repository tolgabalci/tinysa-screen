# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, welcome people of every background and level of experience, assume good intent,
criticize ideas rather than people, and leave out harassment of any kind, in issues, pull requests and anywhere else
the project is discussed.

To report behavior that falls short of this, write to the maintainer through
[GitHub](https://github.com/tolgabalci) or open a [private security advisory](https://github.com/tolgabalci/tinysa-screen/security/advisories/new),
which only the maintainer sees. Reports are handled in confidence.
