# Homebrew tap

Casks for Tolga Balci's Mac apps.

```bash
brew install --cask tolgabalci/tap/tinysa-screen
```

| Cask | |
| --- | --- |
| [tinysa-screen](https://github.com/tolgabalci/tinysa-screen) | The screen of a tinySA spectrum analyzer, live on the Mac: GIFs, bands, a peak hold, presenter tools and a command line (`tinysa-screen`). |

Each release is signed with a Developer ID and notarized by Apple, so it opens without a security prompt.
